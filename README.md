## Описание
Приложение для генерации случайных паролей с возможностью настройки параметров, отображением истории и сохранением её в JSON-файл.

## Использование
- Настройте длину пароля с помощью ползунка.
- Выберите типы символов: цифры, буквы, спецсимволы.
- Нажмите "Генерировать" для получения пароля.
- История сгенерированных паролей отображается ниже.

## Пример
1. Установите параметры.
2. Нажмите "Генерировать".
3. Посмотрите результат и историю.
